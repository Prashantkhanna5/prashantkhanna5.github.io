# PK AI Studio — Portfolio v4

This release adds **PK AI Studio 360** as a flagship portfolio project, including its LinkedIn thought-leadership workflow, multi-cloud architecture publishing, long-form articles, curated Job Radar, interview preparation cockpit and cost-conscious runtime model.

## Deploy to GitHub Pages

1. Extract this ZIP.
2. Upload the **contents** of this folder to the repository root (not the containing folder).
3. Confirm that `index.html`, `styles.css`, `script.js`, `robots.txt`, `sitemap.xml`, and the `assets/` directory are all at the repository root.
4. Commit the files to the `main` branch.
5. Confirm GitHub Pages is publishing from `main` and `/(root)`.

## Profile photo

The profile photo is loaded from `assets/prashant-khanna.webp`. Keep the filename and folder name exactly as shown; GitHub Pages paths are case-sensitive. After deployment, verify: `https://prashantkhanna5.github.io/assets/prashant-khanna.webp`.

## Contact links

The public site includes LinkedIn and email contact actions only. It does not show a GitHub profile or repository link. Your email address is used only in `mailto:` actions and is not displayed as visible page text.

## Cost claim

PK AI Studio is described as designed for $0 operating cost using personal API keys, browser-based rendering and local storage. API provider pricing and quotas can change, so the portfolio includes a qualification that real usage may incur charges.
